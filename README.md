# Personalized Movie Recommendation AI

This project is a college 8-week effort focused on building a personalized movie recommendation system.

## Model 1
Content-based filtering using MovieLens data, Pandas, NumPy, scikit-learn, and cosine similarity.

## Model 2
A future deep-learning recommendation model using TensorFlow/Keras.

## Application
A Streamlit interface will be added later to provide the user-facing experience.

## Project structure

- `data/raw/` for raw dataset files
- `data/processed/` for cleaned/processed data
- `notebooks/` for exploratory and model notebooks
- `src/` for reusable Python modules
- `models/` for saved trained models
- `app.py` for the eventual Streamlit app

## Planned workflow
1. Set up the development environment and project structure.
2. Explore the MovieLens dataset in notebooks.
3. Build the content-based recommendation model.
4. Evaluate and refine the model.
5. Add a Streamlit UI.
6. Explore a TensorFlow/Keras deep-learning alternative if time permits.

- MovieLens data will be added later when explicitly requested.
